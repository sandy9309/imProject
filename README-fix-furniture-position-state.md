# `fix/furniture-position-state`

## 功能目的
明確記錄家具是否曾經擺放，不再使用 `(0,0,0)` 判斷是否為新家具。

## 修改範圍
- 家具資料加入可序列化的擺放狀態。
- 首次生成與已儲存位置使用不同流程。
- 世界原點保留為合法家具座標。

## 驗收條件
1. 未擺放家具生成在玩家前方。
2. 已擺放家具載入後端位置與旋轉。
3. 位於 `(0,0,0)` 的家具可正確保存及還原。

## 建議測試
- 新家具、一般世界座標、世界原點，以及重新登入後載入。

## 分支狀態
功能已完成修改，等待 Unity Editor、後端與 Quest 實機測試。
