# `fix/furniture-unique-id`

## 功能目的
以資料庫 `index` 唯一辨識家具，允許相同模型的多件家具同時存在。

## 修改範圍
- 家具名稱加入 index。
- 生成及刪除改以 index 查找。
- 快取更新與座標儲存只比對 index，不依賴名稱或 URL。

## 驗收條件
1. 相同模型、不同 index 可同時存在。
2. 刪除只影響指定 index。
3. 移動與儲存不會更新另一件同模型家具。

## 建議測試
- 建立兩件相同 URL、不同 index 的家具，分別移動、儲存與刪除。

## 分支狀態
功能已完成修改，等待 Unity Editor、後端與 Quest 實機測試。
