# `fix/blueprint-screenshot`

## 功能目的
提高藍圖截圖上傳可靠性，避免無專案上傳、重複上傳與臨時材質洩漏。

## 修改範圍
- 沒有專案 ID 時禁止截圖上傳。
- 上傳完成前維持 `isTakingScreenshot` 鎖定。
- 上傳加入 15 秒 timeout。
- 共用並在結束時銷毀藍圖材質。

## 驗收條件
1. 無專案 ID 時顯示提示且不送請求。
2. 上傳中連按 X 不會產生重複截圖。
3. 成功、失敗或逾時後都可再次截圖。
4. 連續截圖不會持續累積藍圖材質。

## 建議測試
- 正常上傳、斷網、無專案 ID、連按 X、連續截圖十次。

## 分支狀態
功能已完成修改，等待後端整合與 Quest 實機測試。
