# `fix/model-load-failure`

## 功能目的

修正從網路下載或建立 GLTF/GLB 家具模型失敗時，場景殘留空物件、Rigidbody 維持鎖定，以及家具互動流程無法繼續的問題。

## 預計修改範圍

- `ModelLoader.cs` 的模型下載與實例化流程。
- 下載失敗、實例化失敗和例外發生時的清理程序。
- Rigidbody 原始狀態的恢復。
- 提供玩家與開發者可理解的錯誤訊息。
- 防止等待 `isKinematic` 的協程永久卡住。

## 不在此分支處理

- 家具唯一 ID。
- 家具初始位置判斷。
- Collider 簡化或效能最佳化。
- API 網址、認證與 HTTP/HTTPS 設定。
- 家具碰撞、貼牆和旋轉行為。

## 驗收條件

1. 使用有效模型 URL 時，家具可以正常生成與互動。
2. 使用無效或無法連線的 URL 時，不會留下空家具物件。
3. GLTF 下載成功但實例化失敗時，也會清除家具外殼。
4. 載入失敗後不會留下永久 `isKinematic` 或永久等待的協程。
5. 失敗原因會顯示在 Unity Console，以及已綁定的 VR 除錯文字。
6. 載入其中一件家具失敗，不影響玩家繼續載入其他家具。

## 建議測試案例

- 正常可下載的 `.glb` URL。
- 回傳 404 的 URL。
- 逾時或無法連線的 URL。
- URL 可下載，但內容不是有效 GLTF/GLB。
- 模型下載期間切換專案或刪除家具。

## 分支狀態

功能程式已完成修改，等待 Unity Editor 與 Quest 實機測試。
