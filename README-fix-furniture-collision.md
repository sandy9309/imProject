# `fix/furniture-collision`

## 功能目的

修正家具放下時的重疊判斷、回彈位置，以及回彈後 Rigidbody 與 Collider 狀態互相矛盾的問題。

## 修改範圍

- 只把具有 `FurnitureTag` 的物件判定為家具。
- 抓取期間持續記錄最後合法位置與旋轉。
- 放下重疊時回到最後合法位置。
- 無論正常放置或回彈，都恢復一致的非 Trigger、重力與非 Kinematic 狀態。

## 不在此分支處理

- 牆面防穿透、表面吸附、模型 Collider 建立與 API 儲存。

## 驗收條件

1. 家具不可重疊放置。
2. 重疊時回到移動過程中的最後合法位置。
3. 回彈後仍有正常碰撞、重力且可再次抓取。
4. 玩家或其他非家具 Rigidbody 不會被誤判成家具。

## 建議測試案例

- 家具對家具重疊。
- 家具靠近但未重疊。
- 家具碰到玩家、控制器或其他非家具 Rigidbody。
- 回彈後立刻再次抓取。

## 分支狀態

功能程式已完成修改，等待 Unity Editor 與 Quest 實機測試。
