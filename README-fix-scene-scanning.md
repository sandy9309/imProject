# `fix/scene-scanning`

## 功能目的
優先載入 Quest 裝置內既有 MRUK 房間，只有沒有可用資料時才自動要求重新掃描。

## 修改範圍
- 啟動時呼叫 `LoadSceneFromDevice`。
- 成功取得目前房間時跳過強制掃描。
- 新增 `autoScanWhenNoSavedScene` 與等待時間設定。
- 掃描後確認是否真的取得房間。

## 驗收條件
1. 已有房間資料時不出現重新掃描介面。
2. 沒有房間且開啟自動掃描時正常要求掃描。
3. Y 鍵仍可手動重新掃描。
4. 掃描後沒有房間時輸出警告。

## 建議測試
- 首次使用、已有 Room Setup、關閉自動掃描及掃描取消。

## 分支狀態
功能已完成修改，等待 Quest 實機測試。
